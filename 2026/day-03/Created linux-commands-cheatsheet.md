# 📁 File System

* `cd` → Change directory
* `cd ..` → Go back to previous directory
* `pwd` → Show current working directory

* `ls` → List files
* `ls -l` → Detailed list of files
* `ls -a` → Shows hidden files
* `ls []` → take you to required directory

* `mkdir` → Create a folder
* `touch` → Create a file
* `mv` → Move or rename a file/directory
* `rm` → Remove a file/directory
* `cp` → copy a file
* `cp -r` → copy recursively multiple files/directory
* `cat` → Read file
* `head` → View beginning of file
* `free` → Shows memory usage
* `df` → Disk file system usage
* `df -h` → Disk file system usage

# ⚙️ Process Management Commands

* `ps` → Snapshot of processes
* `ps -a` → Active processes
* `ps -aux` → Detailed process view
* `top` → Live process monitoring
* `htop` → Live scrolling view of process monitoring
* `man` → manual for linux commands
* `kill [PID]` → Kill/terminate a process
* `ps aux | grep ping` → Shows specific processes and detailed.
* `ps a | grep ping` → Shows specific processes


---

# 🌐 Networking Commands

* `ip -d addr` → Detailed IP information
* `ip addr` → Show IP addresses
* `ping` → ping a websites/connects to the server
